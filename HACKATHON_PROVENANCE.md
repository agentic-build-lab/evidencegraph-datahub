# Hackathon Provenance

EvidenceGraph is a new project created for the **Build with DataHub: The Agent
Hackathon** during the official July 6–August 10, 2026 submission period.

## New work

The EvidenceGraph product concept, source code, deterministic fixtures,
generated migration templates, tests, documentation, visual assets, demo, and
submission materials were created during the hackathon period. The repository
history and release tag will be the canonical record of that work.

EvidenceGraph does not reuse source code, media, generated outputs, repository
history, or submission text from the entrant's earlier MandateGuard project.
MandateGuard addresses transactional mismatch detection and reconciliation;
EvidenceGraph addresses preventive data-change assurance and produces
cross-system migration code, validation receipts, and an evidence ledger.

## Permitted building blocks

The project uses standard open-source development tools and libraries,
including DataHub, Python, the Model Context Protocol SDK, DuckDB, dbt, Apache
Airflow, Pydantic, Typer, SQLGlot, PyYAML, Rich, and pytest. Their licenses and
notices are tracked in `LICENSE`, `NOTICE`, and `THIRD_PARTY_NOTICES.md`.

AI coding assistance was used as a development tool. Project-specific product
decisions, implementation, tests, documentation, and submission materials were
created for this entry and reviewed against deterministic evidence.

## Data and privacy

The demonstration uses synthetic commerce records and invented asset, team,
dashboard, feature, model, and deployment names. It contains no customer data,
private tenant metadata, credentials, cookies, or personal information.

## Release disclosure

The release manifest records the canonical commit, tag, public links, and
verification gates. No project-specific pre-existing source or media asset was
added after this disclosure.
