EvidenceGraph — DataHub-Native Change Assurance Agent | 3/7 → 7/7

## Description

EvidenceGraph turns a breaking data change into a complete, evidence-bound
impact map, a nine-file migration pack, deterministic validation receipts, and
a governed decision about whether an agent is allowed to act.

The demonstration compares the same declared synthetic change under two
conditions. Repository evidence finds 3 of 7 downstream consumers. DataHub's
context graph recovers all 7 of 7—including the executive dashboard, ML
feature, model, and production deployment—and supplies the provenance required
to authorize reviewable proposals. Remove one lineage page and EvidenceGraph
caps confidence, quarantines every draft, and produces zero write-back
proposals.
